🎮 GameZone Retro

Página promocional desenvolvida em HTML para a loja fictícia GameZone Retro, especializada em jogos e consoles clássicos.

📋 Sobre o projeto

O projeto foi desenvolvido como parte de um desafio de HTML, com o objetivo de criar uma página compacta, organizada e funcional, utilizando os principais elementos da linguagem.

A página apresenta a loja, seus produtos e informações relacionadas ao universo dos jogos clássicos.

🎯 Objetivo

Criar uma página HTML com no máximo 50 linhas, demonstrando o uso dos seguintes recursos:

Estrutura básica de uma página HTML

Títulos e parágrafos

Textos em negrito e itálico

Lista de consoles ou jogos

Links internos e externos

Imagem relacionada ao tema

Tabela com produtos e preços

🛠️ Tecnologias utilizadas

HTML5

📌 Funcionalidades

A página contém:

🎮 Apresentação da GameZone Retro

📝 Textos formatados com negrito e itálico

📋 Lista de consoles ou jogos clássicos

🔗 Link interno utilizando âncora

🌐 Link externo para uma página relacionada a jogos

🖼️ Imagem temática

💰 Tabela com produtos e seus respectivos preços

▶️ Como executar

Baixe ou clone este projeto.

Abra a pasta do projeto.

Abra o arquivo index.html em qualquer navegador.

A página da GameZone Retro será exibida.
